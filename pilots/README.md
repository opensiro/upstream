# Technical intervention pilots

Each subdirectory records a source-pinned technical proposal or patch and, where available, native reproduction/test receipts. Some are only screened, some have local fixes, and others reached separately authorized external PRs. Directory presence is **not** evidence of upstream adoption or an autonomy grade.

Start with [assessment-to-improvement](../docs/ASSESSMENT_TO_IMPROVEMENT.md) and [native functional effects](../docs/FUNCTIONAL_EFFECTS.md); use the pinned source and individual `CONTRIBUTION_HANDOFF.md` or screening receipt inside the relevant pilot.

The [Kram S2 replay](kram-s2/README.md) demonstrates native file-operation tests but does not establish live provider-driven agent improvement. External publication is always a separate decision.

For the broader portfolio and current PR state see [DASHBOARD.md](../DASHBOARD.md), [HARNESS_STATUS.md](../HARNESS_STATUS.md) and [UPSTREAMING.md](../UPSTREAMING.md).
