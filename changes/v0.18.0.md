# v0.18.0 — Whole-repository C constructors and independent Roadmap reruns

**MINOR release candidate · 2026-11-19.** This bundle is proposed after the published [v0.17.0](https://github.com/opensiro/upstream/releases/tag/v0.17.0). The owner requested another patch-or-minor version; the protocol-wide change in the decision/research contract makes this a **MINOR** candidate. This file is **not** proof an immutable tag or GitHub Release was published.

## Included normative changes

1. **Whole-harness six-function priority** — merged [PR #60](https://github.com/opensiro/upstream/pull/60) requires current source review of **S1/S2/S3/S3*/S4/S5**, across supported runtime, docs, configuration, plugin modes, tests and original contribution history, **before** choosing P0. `S3` is not a default. A legitimate parent-governed S5, intentionally omitted S4 or `NO_QUALIFIED_C_TARGET` is a source-backed result, not a compulsory missing component.
2. **Function-specific C-construction goal** — choose one accepted historical `Sx=[state] → proposed Sx=C` or explain why no C target qualifies. Track A (first-party shipped code and original Issues/PRs) and Track B (an independent minimal on-top constructor with lawful decision rights and real later feedback) are simultaneous; existing work is not an automatic veto, and a low grade is not an implementation mandate.
3. **Human / AI / Receipt redesign** — Human presents the complete six-function historical/current/priority mapping once; AI provides source-specific interfaces and validation without mandated Paperclip five-port or nine-test examples. The canonical `roadmap.md` owns accepted vector, P0/P1/P2, proposal verdict and independent research state. An untested, complete and source-grounded proposal can be **`GO + NEEDS_EVIDENCE`**. No native tests or new Index grade are inferred.
4. **Original-maintainer-facing VSM transparency** — the external architecture Issue opens with a concrete first-party proposal, followed by a short complete six-function VSM assessment, Skills-defined state legend and pinned provenance. It does not demand original maintainers adopt VSM or implement all six functions. External/public communication continues to require exact separate approval.
5. **Independent review chat handoff** — [docs/ROADMAP_INDEPENDENT_RERUN.md](../docs/ROADMAP_INDEPENDENT_RERUN.md) defines the concise fresh-context single-harness prompt for [rerun cohort #58](https://github.com/opensiro/upstream/issues/58). Historic OpenSiro verdicts are withheld until after a new first-source/Index and two-track decision, then compared without overwriting provenance.
6. **Roadmap inventory correctness** — source script `scripts/roadmap_view.py` now recognizes a **canonical case in a legacy `*-pilots-*` folder as a ROADMAP**, not an historical-only template, and selects explicit `Research disposition` over narrative `Result: PLAN_ONLY`. This addresses the verified [Paperclip current case](https://github.com/opensiro-contributions/paperclip/commit/9ce86dd8308ef8d69e4806866e2471389ac38b33) with older comparison files retained.

## Permissions, limitations and publication

This release changes the **Upstream research procedure**, not VSM Profile semantics, Skills grading, Index assessments, product source, authority or third-party rights. `PAUSE/STOP` continues to prohibit fork writes. `ALLOW` is not permission for original/fork-public communication or automatic implementation. The public Issues and PRs of external maintainers remain a separate exact current-conversation approval gate.

The final v0.18.0 tag and GitHub Release must match a validated integration commit, this `VERSION`, changelog and package **after the required owner scope/final SHA authorization**.
