# v0.17.0 — VSM-first contribution-on-top roadmap and consolidated Upstream protocol

**Owner-agreed MINOR bundle · 2026-11-19.** This package consolidates original-repository changes integrated after the last previously published [v0.13.0](https://github.com/opensiro/upstream/releases/tag/v0.13.0) release, including the newly approved parallel contribution-on-top requirement. A version file and this package alone do not establish a tag or GitHub Release; verify [v0.17.0](https://github.com/opensiro/upstream/releases/tag/v0.17.0) independently.

## Normative highlights

1. **Parallel contribution-on-top, VSM-first ([PR #57](https://github.com/opensiro/upstream/pull/57)).** An accepted Index VSM lead triggers two parallel analyses: (A) current first-party code and original Issues/PRs/maintainer decisions; (B) our own independently formulated reuse, integration, extension or adjacent improvement. Compare what already exists, actual coverage, smallest on-top delta, new user outcome and falsifier **before P0 and final GO/NO_GO/BLOCKED**. A nearby maintainer issue is not an automatic NO_GO; an Index grade gap alone is not an implementation mandate. Scope any NO_GO to the evaluated contribution rather than the whole harness. Human/AI templates, guide, selector and regression tests reflect this obligation; the receipt validator opts in new-case fields without invalidating older immutable receipts.
2. **Index-first roadmap candidate and assessment admission ([PR #51](https://github.com/opensiro/upstream/pull/51), [#53](https://github.com/opensiro/upstream/pull/53)).** Source-pinned accepted included Index assessments precede named roadmap and upgrade work. `roadmap_select.py` surfaces candidate leads; historic grades never certify current implementation or a new constructor. Stale assessments trigger an advisory, not a new grade.
3. **Source-native, bounded roadmap completion ([PR #33](https://github.com/opensiro/upstream/pull/33)–[#54](https://github.com/opensiro/upstream/pull/54), multiple independent merges).** One named harness, Human + AI source-backed case, C sufficiency/rights and acceptance, native Issue/PR overlap, terminal GO/NO_GO/BLOCKED, independent publication approval and one-pass research without intermediate operator waiting. Qualified missing forks are created only with verified legal/provider rights; metadata lives on a separate `opensiro/meta` branch with restrictive PAUSE/DORMANT defaults. Legacy case filenames remain historical; new cases use stable unversioned names.
4. **Read-only roadmap statistics and inventory ([PR #50](https://github.com/opensiro/upstream/pull/50), [#55](https://github.com/opensiro/upstream/pull/55)).** Run `scripts/roadmap_view.py` first for counts, coverage, distributions and case status, not a manual API approximation; selection and contribution aggregation retain separate authority. Incomplete inventory remains explicitly PARTIAL/NOT VERIFIED.
5. **Capability-first Upgrade and source-native validation ([PR #7](https://github.com/opensiro/upstream/pull/7), [#12](https://github.com/opensiro/upstream/pull/12)–[#29](https://github.com/opensiro/upstream/pull/29)).** Qualify real user outcomes, function/owner rights, cheapest existing alternative, material capability delta and native tests. Lock one original for an Upgrade, retain five-link handoffs and AI disclosures through context resets, validate fork-local reviews, and require separate exact public approval for every fork/external issue, PR or comment.
6. **Source, rights and selection preflight ([PR #9](https://github.com/opensiro/upstream/pull/9), [#10](https://github.com/opensiro/upstream/pull/10), [#28](https://github.com/opensiro/upstream/pull/28), [#29](https://github.com/opensiro/upstream/pull/29)).** Check license text, contributor rules, CLA/DCO and autonomous PR path before popularity scoring; retained distinct candidate/batch commands make no PR quota. The Human gate issue type records actual required decisions without impersonating human assent.
7. **Fork-local evidence and monitoring ([PR #15](https://github.com/opensiro/upstream/pull/15), [#20](https://github.com/opensiro/upstream/pull/20)–[#27](https://github.com/opensiro/upstream/pull/27)).** Preserve schema-v2 provenance and origin classification, source-owned original PR/issue statuses, optional issue watching and authoritative owner PAUSE/STOP; no second mutable central ledger.
8. **Dated external-PR activity/reporting ([PR #6](https://github.com/opensiro/upstream/pull/6), [#8](https://github.com/opensiro/upstream/pull/8), [#18](https://github.com/opensiro/upstream/pull/18), [#19](https://github.com/opensiro/upstream/pull/19), [#21](https://github.com/opensiro/upstream/pull/21)).** Source-dated dashboard/calendar and CI reporting remain read-only observations; publication status is from original GitHub. Historical activity counts are not live verified benefit.

## Compatibility and authority

- The earlier **0.14.0 / 0.15.0 / 0.16.0** numbered main snapshots and change packages are retained; **no separate matching Releases/tags are backfilled**. The [old v0.16.0 release candidate](../docs/RELEASE_CANDIDATE_v0.16.0.md) is preserved and marked superseded.
- This is a release of an **operating protocol**, not a third-party harness, Profile, Skills methodology, Index assessment, product implementation, accepted autonomous VSM grade or measured engineering-cost reduction.
- Original code, licensing, CLA/DCO, maintainer review and source-native tests remain first-party obligations. Fork `PAUSE/STOP`, separate exact current-conversation public approval, and S5 authority are unchanged. No automatic external communication, public fork PR or issue publication, or cross-repository delegation follows.
- Protocol/receipt tests are synthetic contract checks, **not** proof that Goose, Paperclip or any other harness has shipped the proposed VSM constructors. A structural validator PASS is not semantic review.
- Open unrelated [Upstream PR #30](https://github.com/opensiro/upstream/pull/30) was intentionally **excluded** from this release scope until separately reviewed/merged.
