## Protocol changes

1. **Feature-opportunity evidence before a new upgrade cohort.** Check original-project demand/backlog, source-native missing workflows and possible deterministic test seams. Prefer independently verified source-first leads when present, while keeping Index-first immutable hypotheses truly pre-source and recency fallback explicitly disclosed. Do not pretend recency measures product need.
2. **Six discriminating function probes.** For S1/S2/S3/S3*/S4/S5 per source, record the specific original observation, reason a feature is already available/out of scope, or a precise untested/blocked native scenario. Repeated generic `scoped code inspected` placeholders cannot substantiate deep screening. Six native runtime tests per source are **not** required.
3. **Evidence-closure before claiming research completion.** For a promising candidate with `need=PENDING` and/or `counterfactual=PENDING`, run a minimal permitted, reproducible first-party native falsifier when feasible, capturing exact execution evidence. Otherwise disclose the attempted step/exact dependency, runner, policy or maintainer gate; retain a bounded owner/next check rather than promoting unknown into `PASS` or `FAIL`. Strict-derived technical proof still requires a separate deterministic runner.
4. **Split screening and opportunity conclusions.** Reports must distinguish `SCREENING_COMPLETE` six-function coverage from `OPPORTUNITY_DECIDED` or `OPPORTUNITY_RESEARCH_PENDING` product-native investigation. These are **prose report labels only**, not new manifest stages, status machine or scheduler. Negative results, duplications, and responsibly blocked work remain first-class.
5. **Research continuation over repeated shallow recency waves.** Prioritize a nonduplicate, source-owned deeper follow-up for promising pending candidates before another recency-only cohort where justified by the evidence and effort. An already reserved source requires its original owner/revisit gate, not a new overlapping row.

The diagnosis is [PR #301](https://github.com/opensiro/upstream/pull/301): batch 39 recorded ten original sources and sixty source-probe rows, **50/60** with no specific preregistered function hypothesis, **59/60** generic post-source dispositions, **9/10** primary opportunities pending both need and counterfactual, and one existing trace-export capability. **That was a bounded completed screening, not a completed search for useful new functionality.**
