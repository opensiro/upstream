Live GitHub stars inform potential **reach only**; mechanism specificity, first-party code evidence, the maintainers' likely acceptance, verification cost and non-duplication should govern actual work selection. Screen observations are not yet `ASSESSMENT_DERIVED` outcomes: register falsifiable hypotheses before fresh source/issue inspection under Upstream #56 and verify changes through a distinct deterministic native runner/CI.
