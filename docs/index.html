How to read these numbers

Henterprise ≠ two merged contributions

The contributor's original PR #1 was closed, and a maintainer's replacement #3 merged with source authorship preserved. This is one merged intervention, with multiple actors.

StarNet ≠ a merged contributor PR

The maintainer independently implemented the proposed feature and credited its origin. The original contributor PR #56 remains open. Influence is visible without misattributing code.

Shep is two interventions

Agent coordination and the ESM startup fix have separate PRs and independent fit conclusions. Their current lifecycle is verified in the table, not inferred from old CI notes.
