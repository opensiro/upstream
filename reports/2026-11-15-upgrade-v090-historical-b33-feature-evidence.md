## New operator capability: distinguish same-agent tasks in Gentle Shell's Agents view

**Origin:** **`SOURCE_FIRST` / `GENERAL_UPSTREAM` only**, specifically current first-party [Gentle Shell issue #3259](https://github.com/Gentleman-Programming/gentle-shell/issues/3259), referring to [closed #939](https://github.com/Gentleman-Programming/gentle-shell/issues/939). This user request was discovered *after* the frozen batch 33 Index-first S2 scope question and **cannot be retroactively labeled `ASSESSMENT_DERIVED`**.

**User action:** An operator launches two concurrent delegated tasks with agent `explore`, opens the Agents view, and selects the correct task by its existing label without opening each child thread. Existing alternative: the sidebar card already shows each task's label, but the richer Agents view renders duplicate `Subagent explore` rows; inspecting child threads to identify tasks breaks the quick navigation workflow. This is new *view-specific decision information*, not a model-quality claim or changing the agents' permissions.
