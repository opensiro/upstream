# Licensing scope — OpenSiro upstream contribution portfolio

**Original OpenSiro-authored prose** in this portfolio (including descriptions and project notes) is proposed under [Creative Commons Attribution 4.0 International](LICENSE), to the extent its contributors hold and authorize the necessary rights.

**Original machine-readable registry data** in `registry.yaml` is separately dedicated to the public domain using [CC0 1.0 Universal](LICENSES/CC0-1.0.txt), to the extent its authors have the necessary rights. The `registry.yaml` SPDX header makes this machine data exception explicit. Third-party factual links and project identifiers are referenced for identification only, not claimed as OpenSiro-owned creative content.

**Excluded from these grants:** upstream software/source codes (including Cognee), foreign trademarks/logos, GitHub user identities, third-party documentation/assets, separately licensed code or datasets, and any other materials whose rights OpenSiro does not control. Active fork repositories preserve their upstream license notices.

This portfolio registry is not a fork mirror and does not change an upstream PR status, integration permission, or contribution ownership. No prior license is revoked. Maintainers must confirm contributor/rightsholder consent, especially for the irrevocable CC0 dedication, before merging this **draft** proposal.
